# Servisku - Frontend

Servisku adalah website cek estimasi servis motor berdasarkan tipe kendaraan. Website ini membantu pengguna melihat komponen servis seperti oli mesin, oli gardan, v-belt, busi, filter udara, kampas rem, ban, dan komponen lainnya.

Frontend dibuat menggunakan React, Vite, Tailwind CSS, React Router, dan Lucide Icons.

## Fitur

- Landing page modern dan responsive
- Pencarian motor
- Daftar motor dari API Laravel
- Filter motor berdasarkan brand, kategori, dan transmisi
- Detail estimasi servis motor
- Tampilan card komponen servis
- Integrasi dengan Laravel API

## Teknologi

- React
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React
